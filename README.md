## Introduction
This repository is a collection of Python scripts that demonstrate various cybersecurity concepts, such as brute force attacks, dictionary attacks, password strength checking, encryption, and decryption. These scripts are intended for educational purposes and should only be used in environments where you have explicit permission to test security.

---

## Scripts Overview

### 1. **Brute_Force_Attack.py**
   - A script to perform a brute force attack on a password-protected system or file.
   - **Usage**: `python Brute_Force_Attack.py <target>`

### 2. **CLI_keychain.py**
   - A command-line interface (CLI) tool to manage and store passwords securely.
   - **Usage**: `python CLI_keychain.py`

### 3. **Dictionary_Attack.py**
   - A script to perform a dictionary attack using a list of common passwords.
   - **Usage**: `python Dictionary_Attack.py <target> <dictionary_file>`

### 4. **Password_Strength_Checker.py**
   - A tool to check the strength of a password based on complexity and length.
   - **Usage**: `python Password_Strength_Checker.py <password>`

### 5. **cli_password_tool.py**
   - A CLI tool that integrates password cracking and strength checking functionalities.
   - **Usage**: `python cli_password_tool.py`

### 6. **encryption_decryption.py**
   - A script to encrypt and decrypt text using a symmetric key.
   - **Usage**: `python encryption_decryption.py <encrypt/decrypt> <text> <key>`

### 7. **encryption_key.py**
   - A script to generate and manage encryption keys.
   - **Usage**: `python encryption_key.py`

### 8. **generate_key.py**
   - A tool to generate secure encryption keys.
   - **Usage**: `python generate_key.py`

### 9. **password_generator.py**
   - A script to generate strong, random passwords.
   - **Usage**: `python password_generator.py <length>`

### 10. **password_storage.py**
   - A tool to securely store and retrieve passwords.
   - **Usage**: `python password_storage.py`

### 11. **random_passwords.txt**
   - A text file containing a list of random passwords for testing purposes.
